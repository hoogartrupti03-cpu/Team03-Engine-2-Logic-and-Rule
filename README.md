# Engine 2 – Logic and Rule

## Project
Interior Design and Recommendation System

## Team
Team No: 03

## Purpose
Processes user requirements and determines the suitability of interior designs based on room type, dimensions, preferred style, colour theme, and budget.

## Technologies Used
- JavaScript
- React.js
- Node.js

## Implementation
- Room-type matching
- User preference matching
- Design-style matching
- Colour preference matching
- Budget-based filtering
- Room-size consideration
- Suitability-score calculation
- Sorting and ranking of recommended designs
- Displaying alternative designs when no designs match the selected budget

## Recommendation Criteria
The recommendation system evaluates available designs based on:
- Selected room type
- Preferred interior design style
- Preferred colour theme
- Estimated budget

## Suitability Score
The system calculates a suitability score using matching criteria:
- Base score: 40
- Style match: +30
- Colour match: +20
- Within-budget match: +10

Designs are sorted according to their suitability scores.

## Main Files
- `Results.jsx` – Contains the recommendation logic and displays matching interior designs.
- `Results.css` – Defines the styling of the recommendation results page.

## Expected Output
Ranked interior design recommendations based on user requirements, helping users explore suitable interior designs.
